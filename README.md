# Guides Theme

Hugo theme shared across all guides in the [gpeyet-learning](https://github.com/gpeyet-learning) ecosystem.

Built with Bootstrap 5.3, SCSS, and Bootstrap Icons. Supports dark/light mode natively.

Used as a Hugo Module — import it in any guide or hub project:

```yaml
module:
  imports:
    - path: github.com/gpeyet-learning/guides-theme
```
